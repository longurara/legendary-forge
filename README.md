# legendary-forge

**Lò Rèn Huyền Thoại** – game roguelite 3D góc nhìn từ trên xuống, viết bằng three.js + Vite.
Đánh quái, nhặt vũ khí, rèn hai vũ khí thành một vũ khí mạnh hơn, xuống từng tầng hầm và hạ boss.

## Chạy thử

```bash
npm install
npm run dev
```

Mở http://localhost:5173

## Điều khiển

| Phím | Tác dụng |
|---|---|
| WASD | Di chuyển |
| Chuột trái | Tấn công |
| Chuột phải | Kỹ năng vũ khí |
| Space | Lướt né |
| R | Tuyệt kỹ (khi thanh Nộ đầy) |
| E | Nhặt / tương tác / rèn |
| Q | Đổi vũ khí |
| X | Phân rã vũ khí thành Mảnh Thép |
| F | Cường hóa vũ khí ở đe |
| Esc | Tạm dừng |
